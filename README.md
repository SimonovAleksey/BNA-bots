# BNA-bots
Репозиторий, хранящий в себе все материалы и файлы для реализации типового проекта bots (Осень 2025) "Беспилотный наземный аппарат"

Для сборки корпуса и шасси скачайте и разархивируйте файл сборки. Полученный .STEP файл импортируйте в удобный слайсер и там разбейте на компоненты. Удачной печати!

Для сборки потребуются:
- винты М3х35 24 шт
- винты М3х10 24 шт 
- винты М3х12 48 шт
- винты М3х20 12 шт
- винты М3х40 12 шт
- винты М2х12 24 шт
- винты М2.5х8 4 шт
- шайбы М3 36 шт
- гайки М3 12 шт
- шайбы М6 24 шт
- 
Рекомендованные материалы:
- PETG для шасси и корпуса
- TPU для гусениц
